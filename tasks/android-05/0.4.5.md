# 0.4.5：工作台与变更检索

状态：PRD 已建立，尚未实施/验收/发布。依赖：0.4.4；属于 [0.5 路线](../prd-android-05.md)。

## 更新计划

1. 工作台从无差别工具清单调整为当前任务上下文、任务工具和全局管理三个层次。
2. 为 Git Review 增加已加载文件的路径搜索和类型筛选，保留来源范围、分支与总览。
3. 完整区分无变更、无匹配、读取失败及旧数据刷新失败。
4. subagent 实现独立筛选逻辑、原生 UI 和单元测试，主 agent 检查 API 一致性及返回路径。

## PRD

### US-451：在当前任务下找工具

作为用户，我需要知道工具作用于哪个任务与目录，并能两次操作内进入项目文件或 Review。

- FR-451：顶部显示当前任务标题与可用的目录名/状态；无任务时提供返回对话的明确动作，不虚构数据或创建任务。
- FR-452：任务队列、项目文件、代码 Review、侧线程归为任务工具；目录管理和用量统计归为全局管理，入口附简短用途。
- FR-453：保持现有工具路由、功能和权限；不显示不存在的远端分支或同步状态，不新增直接 Git 写 API。

### US-452：快速定位已加载的变更

作为用户，我需要按路径或状态缩小变更文件列表，同时知道是否仍有实际变更。

- FR-454：Review 提供不区分大小写的路径子串搜索和全部/新增/修改/删除/其他筛选，使用现有已加载文件，不新增后端搜索。
- FR-455：未知状态、重命名、未跟踪文件按明确策略归类并测试；总览统计仍基于全部文件，筛选显示“匹配数 / 总数”。
- FR-456：筛选无结果显示“没有匹配文件”和清除操作，不显示“没有变更”；网络错误继续展示错误和重试。
- FR-457：进入单文件差异后返回保留搜索/筛选及合理阅读位置；更换任务、scope/base 不串入旧任务状态。筛选条件改变时回到结果开头。
- FR-458：保留长文件名信息、未知行数、删除/重命名和差异横向滚动；不把缩短列表称为服务器全库搜索。

## 实施边界

允许：`MobileShell.kt` 的 WorkspaceHome、`ToolsScreen.kt` 的 Review、独立筛选文件和测试；不得改模型提交协议、队列动作或 Web。与前批 UI 文件有重叠，只能前批验收后执行。

## QA / 完成标准

- [ ] 路径大小写、空白、Unicode、状态组合、未跟踪/重命名/未知状态的单元测试通过。
- [ ] 原生 UI：搜索、清空、状态筛选、0 匹配、无变更、错误重试各自断言；不能因筛选增加 API 调用。
- [ ] 打开 diff 后返回保留筛选；任务或范围切换无旧状态污染。
- [ ] 短列表/长列表、长文件名、360dp/深色/2x 字体截图；返回对话保留草稿。
- [ ] 空任务时不会新增服务器任务；原有侧线程/目录/统计入口仍可达。
- [ ] Android unit/lint/build、原生 UI、`npm test`；网页变动另用 Playwright/dev-browser 验证。

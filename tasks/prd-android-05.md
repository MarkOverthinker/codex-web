# Android 0.5：体验、视觉与交付规划

日期：2026-09-12。基线：`0.4.2-preview` / versionCode 11，源码基线 `ea59dda`。状态：0.5.0-preview 已完成实施与候选验收，用户确认后已公开发布；本轮停止。公网浏览器导航限制见发布记录。

## 目标与事实

这是现有 Kotlin / Compose 原生客户端的迭代，不重写成 WebView，也不复制桌面工作区到手机。0.4.2 已具备三图标底栏、项目任务抽屉、队列、草稿保护、文件预览和 Git Review；这些是必须保持的基线，不列为新功能。

本轮目标是提高阅读层级、输入与运行状态的可理解性、工具可发现性及长列表检索效率。先完成确定性、可测试的优化，避免用大面积装饰或新增导航掩盖问题。

## 产品范围与设计原则

- 信息架构继续为「对话 / 工作台 / 我的」，项目抽屉作为跨任务入口，队列是对话内面板。
- 坚持 48dp 高、24dp 图标的紧凑底栏，无可见文字、悬浮底座、阴影或新增导航项目；保留系统安全区和无障碍名称。
- 视觉方向：低饱和靛蓝、克制的琥珀标识、近白/炭灰阅读底色；普通内容少卡片，操作组用薄边界，拒绝大渐变、玻璃效果和无意义动效。
- 常用操作靠近拇指区；危险操作保留确认；一个页面只有一个主要动作。消息操作不靠手势独占。
- 主体文字和状态必须独立可读，不能只靠颜色。字号以 sp、尺寸以 dp 定义，不用缩小字体换取表面整齐。
- 使用成熟 Material 3 组件与现有图标，不引入新字体下载、图像生成、远程资源或 UI 框架。保留原生文本选择、代码、表格和数学渲染。
- 横屏、窄屏和大字体优先保证可滚动、无遮挡，不在本轮实现完整平板多窗工作站。

## 全局功能要求

- FR-G1：草稿、引用、附件、消息、事件、线程和队列继续由现有服务器持久化；不得另建执行器或客户端权威队列。
- FR-G2：保留 Web UID 与 tenant worker UID 分离；不得新增直接执行 Git 命令或绕过确认的客户端入口。
- FR-G3：连接错误、缓存只读、运行中、发送中、结果不确定必须区分；不承诺断网可执行任务，不自动重发不确定请求。
- FR-G4：跨标签、返回、查看文件后保留草稿；不允许欢迎页建议覆盖非空草稿，也不允许自动发送示例。
- FR-G5：图标操作至少 48dp 可点击区域，有描述和选中状态；键盘弹出隐藏底栏，收起恢复，输入框不被系统栏遮挡。
- FR-G6：消息/文件列表继续懒加载；筛选只筛已有数据，明确不冒充全库或服务器全文搜索。
- FR-G7：浅深色使用完整语义色；正文目标对比度 ≥4.5:1，较大文字与有意义非文本目标 ≥3:1；不透明度叠加后的实际颜色也纳入检查。

## 共同 QA 与验收方法

| 层次 | 内容 | 判定 |
| --- | --- | --- |
| 单元 | 现有 JVM + 每批新增确定性逻辑测试 | 无新增失败；记录总数，不沿用历史数 |
| 原生 UI | Compose instrumentation，模拟 API | 功能断言、控件语义与实际截图均检查 |
| 布局 | 360dp 浅色；411dp 深色；1.5x/2x 字体；键盘/返回 | 无关键文字截断、不可达动作或阅读区遮挡 |
| 生命周期 | 重建、账号退出/切换、缓存恢复 | 不泄漏前一账号数据，不丢未提交输入 |
| API 回归 | `npm test` 与 Android API 测试 | 不破坏 Web 或服务器协议 |
| 工程 | Android unit/lint/preview build | 新错误为零，既有警告明确列出 |
| 升级 | 同包名、持久签名、`adb install -r` | 不卸载，不加 `-t`，保留 UID/首次安装时间 |
| 分发 | 发布脚本、固定页、APK SHA-256、HTTP 范围下载 | 重新下载验证，保留历史；失败不得标完成 |

本项目是原生 App，浏览器截图不能替代 Compose/模拟器/真机验收。若改 Web 或下载页，另加 Playwright 浏览器验证；可用 dev-browser skill 时按该工作流执行，不可用则用仓库现有 Playwright。模拟 API 不等于真实账户或 Flyme 真机验收。

## 成功指标

1. 在当前会话下两次操作内进入文件或 Review；检查同一路径前后操作数。
2. 搜索一个已加载的变更路径后只显示匹配项；退出筛选可恢复全部文件且不多发网络请求。
3. 发送/录音/缓存/结果不确定四种状态都有可见说明与正确禁用条件；草稿和重复提交回归全部通过。
4. 紧凑底栏维持 48dp；360dp 和 2x 字体下核心操作可达；正文和语义色对比度达到目标。
5. 每个候选有实际命令、结果和限制；0.5 发布有签名和重新下载证据。性能优化只报告测量结果，不宣称未经测量的百分比提升。

## 非目标与取舍

不做 iOS、不换协议/数据库、不新增推送服务、离线自动执行、自动 Git 提交按钮或整套平板 IDE；不擅自更改已有 API 源、计费或权限设置。首轮采用既有品牌延续而非两套皮肤同时开发。过渡动画只用于反馈，不阻塞操作或不停播放。

待真实使用反馈确认：是否需要长消息大纲、跨任务全文搜索、更多平板布局；这些进入后续 backlog，不阻塞本轮确定性改进。

### 首轮完整 QA 的退回项

2026-09-12：`tmp/android-05-qa/050-all-ui.log` 共 34 项、4 项失败。未据此发布。

- 旧工作台标语断言未随设计变化同步：QA 更新真实上下文断言，保留草稿与阅读位置检查。
- 空任务工作台返回后的草稿为空：由 QA/工作台 agent 增加中间状态检查定位，不允许删除或弱化此断言。
- 单文件 diff 内容未在首次视口显示：区分布局可滚动与内容缺失，保留可达性及筛选恢复验证。
- 首次进入长对话尚未到底（滚动语义值相差 100，不作为像素距离）：对话 agent 检查原生文本重测与视口变化，不能以增加固定 sleep 代替修复。

最终结果必须以修复后重跑为准；本条作为保留的审查历史，不代表最终失败仍存在。

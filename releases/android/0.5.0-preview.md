## 更新

- 统一原生浅深主题、语义色、字号和圆角；保留 48dp 三图标导航与系统安全区。
- 欢迎建议不覆盖非空草稿、引用、附件或关联来源，支持小屏/大字体滚动，不自动发送。
- 输入区准确区分发送、排队意图、转写、缓存和待核对状态，保留服务器确认与重复提交保护。
- 优化作者/操作层级、历史阅读与“回到最新”；区分用户滚动意图和布局变化，处理高于视口的末条回复。
- 工作台按当前任务与全局管理分组；无任务可直接返回原草稿。
- Review 支持已加载文件的路径/类型筛选、匹配计数及独立空态；进 diff 返回保留，切换范围或基准清空；不增加后端搜索或 Git 写 API。

0.4.3、0.4.4、0.4.5 是本轮内部开发里程碑，均有独立更新计划、PRD 与 QA；未伪造这些中间版本的公开发布记录。实施由 Ampere、Poincare、Boyle 承担，Hubble 编写独立 UI QA，主 agent 负责代码审查、退回修复、真正在模拟器执行和截图签收。详情见 [0.5 验收账本](../../tasks/prd-android-05.md)。

交互示意

对话优先

打开即回到聊天。项目任务从左侧滑出，按状态筛选，分组展开，不必穿过管理后台。

随手管理队列

输入框上方的小提示承载排队状态。点击展开操作，关闭仍回到原对话。

本地缓存，局部反馈

加密保留近期浏览和草稿。语音、上传与发送各自在按钮里反馈，不用全屏等待。

开始使用

  1. 下载 APK，在手机文件管理器中打开并安装。
  2. 填写自己的 HTTPS 服务地址，使用现有 Codex Web 账号登录。
  3. 进入对话；右滑查看项目，通过底部导航进入工作台或个人设置。

已有 0.2.1 或后续同签名预览版，请直接覆盖升级，不要先卸载。本机未同步草稿会随卸载而丢失。任务仍在服务器运行；本应用不是离线 Codex。

安装失败或提示不兼容？

先确认下载的是完整 APK，而不是网页。记录文件大小及系统的错误原文；如有电脑，可用 adb install -r 获取明确错误码。不要通过强制降级、测试安装或先卸载来掩盖原因。魅族/Flyme 真机兼容性尚需实际验收。

缓存与隐私边界

浏览快照与草稿按服务器和账号隔离，保存在加密的应用私有存储中。缓存不是完整离线历史库，冷启动仍需验证登录。页面不收集账号密码，无第三方统计脚本。

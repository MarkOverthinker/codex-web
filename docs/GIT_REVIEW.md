# Git Review

从主会话标题区域的 **Review** 打开只读变更面板。点击文件查看带增删高亮和原/新行号的 unified diff，点击刷新重新读取；Escape 关闭。窄屏时文件列表与 diff 上下排列，外观随主题切换。

## 比较范围

- **未提交变更（全部）**：HEAD 对比当前工作区，包含暂存与未暂存的最终合并结果，以及未被忽略的未跟踪文件。已暂存与未暂存改动互相抵消时，该文件可能不出现；单独检查暂存区可切换下一项。
- **仅已暂存**：HEAD 对比 Git index，支持尚未创建首次提交的仓库。
- **分支已提交变更**：所选基准分支与 HEAD 的 merge-base 对比 HEAD，不包含未提交修改。基准可选本地分支及本地已有的远程跟踪分支，不会联网 fetch；无共同祖先时显示错误。

文件统计不包含未跟踪文件和二进制文件的增删行数。重命名按删除旧文件、新增新文件展示。二进制文件、特殊文件和子模块只展示 Git 提供的信息，不递归查看子模块；超大输出报错，单文件文本预览最多 256 KiB 并标记截断。单条 Git 命令输出最多 4 MiB，最长 10 秒；整个 worker 最长 30 秒。刷新或切换文件时读取的是新状态，不是不可变快照；任务仍在修改文件时可能需要再次刷新。

## 权限与实现

`GET /api/conversations/:id/review?scope=working|staged|branch&base=refs/heads/main&file=path`（位于应用 base path 下）。`base` 与 `file` 可省略。接口先检查会话所有权，路径只能从该会话配置确定；文件必须存在于当前变更列表，基准必须是本地可枚举的分支引用。独立工作区禁止向上读取宿主父仓库，host 工作目录则展示所属的整个仓库，包括工作目录在仓库子目录中的情形。

隔离部署由 supervisor 使用对应租户 UID/GID 启动独立 Git worker；host 模式沿用映射的系统账户。不会在隔离不可用时降级到 Web UID 执行。Git 命令不经过 shell，文件使用 literal pathspec，禁用 external diff、textconv、fsmonitor 和可选 index 写锁，不读取全局/系统 Git 配置。未跟踪符号链接不会作为普通文本跟随读取。响应不缓存。

本功能不提供 AI 审查结论、提交、撤销、暂存或远程同步。仓库仍需由可信租户维护；它不是针对恶意仓库配置的通用执行沙箱。

# 仓库工作区（Git Review）

## 使用方式

会话工具中的 **变更** 与 **文件** 打开同一个仓库侧栏，分别进入「审查变更」和「全部文件」。桌面可拖动宽度或展开工作区，窄屏改为覆盖式面板、文件树在预览上方；关闭/Escape/移动端返回回到对话，不清空输入草稿。切换页签保留当前文件、筛选条件与预览方式。

- **环境信息**：分支名旁展开卡片，显示变更文件数、增删行数、远程名称、当前分支、上游与领先/落后数量。远端信息来自本地跟踪引用，不自动 fetch；未配置上游和非 Git 目录明确显示，不冒充已同步或无变更。
- **审查变更**：目录树支持折叠、筛选、文件前后导航与「已查看」标记；同一时间只请求选中的文件。刷新保留仍存在的选择、清除旧的已查看标记；任务状态变化也刷新数据，避免把上次审查的标记当作新内容已审查。
- **差异**：语法高亮、独立原/新行号、增删色块及符号、可折叠差异段与自动换行。未改动的间隔以省略行数表示，不加载完整大文件。超过 1200 条差异行后按批次展开。
- **预览 / 源码**：Markdown 渲染标题、列表、表格、代码与公式；源码带语法高亮和行号。预览严格对应当前范围：工作区读磁盘，已暂存读 index，分支读 HEAD，不用磁盘内容冒充已提交版本。删除、二进制、特殊文件及过大版本显示具体限制。
- **全部文件**：沿用会话目录权限和懒加载文件树，支持代码、Markdown、图片、PDF、复制路径及下载；代码与 Review 复用高亮组件。Markdown 不执行原始 HTML，也不自动加载外部图片；不提供执行任意 HTML/JavaScript 的网页预览。

## 提交与推送

**审查接口仍只读。提交/推送按钮不是直接 Git 写接口，而是经确认创建当前会话的 Codex 任务。**

提交前读取最新工作区列表，填写提交说明并明确勾选文件，默认只勾选仍在列表中的已暂存文件；提示 Codex 仅提交这些文件，保留其他暂存/未暂存内容，不自动推送。若同一文件已有部分暂存，勾选该文件表示请求提交该文件的当前整体改动，而非只提交部分暂存块。快捷推送要求配置上游、存在领先提交且不落后于本地上游引用；执行时还需核对实际远端目标和最新上游状态。冲突、分离 HEAD、归档及当前会话有执行/排队任务时不提供快捷写操作。

操作参数携带仓库真实路径、分支、HEAD、上游、明确路径及提交说明，要求执行器先核对、发现状态变化停止；这是发给 Codex 的执行约束，不是服务端原子 Git 事务，也不是不可变差异快照。其他进程仍可能修改仓库，因此必要时必须重新审查。沿用现有持久化队列、账户身份、沙箱与审批，不新增 bypass，不使用 `git add .`、自动合并、amend、reset、rebase 或强制推送。入队提示不代表 Git 已执行成功，实际结果和失败原因显示在对话中。发起操作不消耗或清空现有草稿及附件。

## 比较范围与限制

- **未提交变更**：HEAD 对比工作区，包含暂存与未暂存的最终合并结果，以及未被忽略的未跟踪文件。暂存/未暂存改动互相抵消时该文件可能不出现；单独检查暂存区可切换下一项。
- **已暂存变更**：HEAD 对比 Git index，支持首次提交前的仓库。
- **分支变更**：所选基准与 HEAD 的 merge-base 对比 HEAD，不包含未提交修改。基准来自本地分支与已有远程跟踪引用；无共同祖先时显示错误。基准选择不会切换当前分支。

增删行统计不包含未跟踪文件和二进制文件，界面标注未计入的文件数；重命名按删除/新增展示；不递归预览子模块。单文件 diff/工作区文本最多 256 KiB，截断时显示提示；大于此限制的 index/HEAD 完整预览不可用。源码 DOM 最多渲染前 4000 行 / 256K 字符，Markdown 渲染最多 256K 字符，完整文件可下载。单条 Git 命令输出最多 4 MiB、最长 10 秒；worker 最长 30 秒；超限明确报错。多条 Git 读取不是原子快照，任务运行时可能需要刷新。

## 权限与实现（需要时阅读）

`GET /api/conversations/:id/review?scope=working|staged|branch&base=refs/heads/main&file=path` 位于应用 base path 下；`base`、`file` 可省略。返回原有 diff 字段以及 `head`、`upstream`、`remotes`（仅名称）、`ahead`、`behind`、`stagedFiles`、`conflictedFiles`，选中文件时带 `preview`。不返回可能含凭据的远端 URL。

接口校验会话所有权，路径只从会话配置确定，文件必须属于当前变更列表，基准必须是本地可枚举引用。独立工作区禁止读取父仓库；host 工作目录则展示其所属仓库，支持从仓库子目录进入。

隔离部署由 supervisor 使用租户 UID/GID 启动 Git worker；host 沿用映射系统账户；隔离不可用时不会退回 Web UID。Git 不经过 shell，使用 literal pathspec，禁用 external diff、textconv、fsmonitor 和可选 index 写锁，不读取全局/系统 Git 配置。普通文本预览不跟随文件符号链接，响应不缓存。Git 写任务走既有消息 API，不改变 supervisor 协议、队列持久化或 UID 分离。仓库仍需由可信租户维护；此读取器不是恶意仓库配置的通用沙箱。

# Android 客户端与移动交互

## 定位与边界

这是第一阶段的可安装混合客户端：**Android 系统能力 + 手机专用 React 交互 + 原有服务端**，不是把桌面布局原样封装，也不是全原生 Kotlin/Compose 重写。客户端不内置服务器或 Codex CLI，不属于 OpenAI 官方产品。

优先复用现有业务组件，避免为独立 App 重写接口时遗漏附件、草稿、排队、侧边线程或高级设置。服务端仍是唯一持久状态来源，Web UID 与 tenant worker UID 的隔离不变。更新服务器前端即可同步手机交互，无需每次重新安装 APK；系统能力的变化需要更新 APK。

当前不承诺已达到任何商业 App 的体验标准。离线执行、推送通知、实时语音通话、后台录音、分享接收、相机直拍和商店发布不在本阶段内；未新增这些功能不影响原有 Web 功能。上传可通过系统文件选择器访问已有文件和照片。下载需要保持 App 进程存活，尚无后台下载服务。

## 安装与连接

1. 使用包含本次移动端修改的服务器版本。宿主模式按项目规范运行 `npm run reload`；不要绕过运行中任务的重启保护。
2. 安装自己构建或可信来源的预览 APK。系统可能要求授予安装来源“安装未知应用”的权限。
3. 输入现有服务的 HTTPS 地址，例如 `https://example.org/codex-web/`。只输入主机时自动补上 `/codex-web/`；反向代理部署在其他路径时填写完整路径，并保证服务也支持该路径。
4. 使用原来的账号密码登录。此 App 的 Cookie 存储独立于系统浏览器，需要单独登录。
5. 任务列表底部头像 → 个人设置 → **安卓连接设置**，可更改服务地址。切换前等草稿保存完成；切换会清除 App 登录及本地缓存，但不删除服务器数据。

要求 Android 8.0 / API 26 或以上，以及可用的 Android System WebView。使用受系统信任的 HTTPS 证书；不支持明文 HTTP、自签证书绕过或地址内嵌密码。自托管网络需要 VPN 时，先连接 VPN。

## 信息架构与功能对应

900 CSS px 及以下启用手机布局，覆盖常见手机横屏；较宽屏幕继续使用桌面工作台。浏览器和安卓客户端共用这一判断。

| 原有能力 | 手机入口 / 处理 |
| --- | --- |
| 会话、新建、搜索、分类、置顶、重命名、删除 | 顶部任务列表；右侧新建按钮；列表中的原操作菜单 |
| 消息、Markdown、数学、代码、引用、编辑重发、Fork | 主聊天区与消息操作；所有原有业务回调保持复用 |
| 模型、API 源分组、思考级别、权限、预设选择 | 输入栏的模型/选项按钮 → 任务选项面板 |
| 上传、剪贴板附件、服务器文件选择 | 输入栏加号；粘贴；任务选项中的服务器文件 |
| 草稿、上传进度、历史消息编辑 | 原服务端草稿与编辑逻辑，打开/关闭工具不重建输入框 |
| 队列、排序、编辑、删除、引导、直接执行、停止 | 原队列卡片和运行进度；输入栏发送/停止按钮 |
| 文件浏览、结果预览、代码定位、下载 | 会话工具 → 文件；结果链接；预览独占手机屏幕 |
| 侧边聊天、多线程历史、上下文引用、提升主任务 | 会话工具 → 侧边聊天；手机全屏打开，不与主聊天挤占宽度 |
| Git 分支 / 工作树 Review | 会话工具 → Review |
| 工作目录、收藏与分类管理 | 会话工具 → 目录；任务列表新建任务旁的目录菜单 |
| 计费统计、费率配置、历史重算 | 会话工具 → API 统计；或个人设置 |
| 历史导入、归档恢复 | 任务列表 → 导入历史会话；个人设置 → 已归档任务 |
| 账户密码、主题、字号、聊天宽度、源管理、预设管理 | 任务列表底部个人设置；原服务端能力开关继续生效 |
| 语音模型、录音、转写 | 语音模型位于“任务选项”；输入栏仅保留发送旁的一个语音按钮，首次录音请求系统权限。录音中再次点击语音按钮仅回填，点击发送则转写成功后发送 |

### 手机交互原则

- 单一顶栏显示当前任务，不再叠加品牌栏和桌面工具栏。
- 工具按需展开为底部面板；点功能后关闭工具面板，进入文件、Review 等独立页面。
- 输入区始终参与布局，而不是固定覆盖消息；跟随可视视口与系统键盘缩放。
- 手机上 Enter 换行，点击发送才提交，主聊天与侧边聊天一致；桌面 Enter / Shift+Enter 行为不变，保留输入法组合输入保护。
- 主要触控目标至少 44 CSS px；工具面板支持焦点约束、背景 `inert`、关闭后恢复焦点。
- Android 返回先关闭顶层面板或菜单，再返回任务列表后的主界面；无可关闭层时返回 Web 历史或将 App 放到后台。不会用返回操作注销或停止服务器任务。
- API 33+ 使用系统 `OnBackInvokedDispatcher`；旧系统使用 `onBackPressed`。仅对这个旧系统兼容方法豁免 `GestureBackNavigation` lint，不屏蔽其他检查。
- App 切入后台时结束正在录制的音频并进入原转写流程，不自动发送转写内容。

## 安全与系统集成

原生端没有 `addJavascriptInterface` 或任意命令执行桥。服务器地址只存在 App 私有偏好设置中，没有内置私人主机、账号或密钥。

- 只允许指定 HTTPS origin 和应用路径在主 WebView 中导航。其他 HTTP(S)、邮件和电话链接交给系统，不允许 `file:`、`javascript:` 或 `intent:` 导航。
- 不忽略 TLS 错误；禁止混合内容、本地文件访问及第三方 Cookie，保留 Safe Browsing。
- 只向当前可信服务授予麦克风权限，必须同时满足系统授权；不请求相机、通讯录或全盘存储权限。
- 上传使用系统文档选择器，取消后正确清理回调；最多返回 12 个附件。
- 下载使用系统保存位置选择器，不申请全盘存储权限。鉴权 Cookie 只发送到当前服务，逐跳检查重定向，不将 Cookie 发往外站。下载失败会提示可能存在未完整保存的文件。
- 显式支持网页 `alert`、`confirm`、`prompt`，保留删除、重命名等流程的确认与取消语义。
- 禁止 App 数据云备份和设备迁移，避免复制登录 Cookie；关闭 WebView 调试。
- WebView 崩溃或页面连接失败时显示原生恢复页，不伪造离线成功。

## 构建与测试

依赖：JDK 17、Android SDK platform 36、Android SDK Build Tools，以及 Gradle Wrapper 所需网络。`android/local.properties` 可设置本机 `sdk.dir`，不要提交该文件。

```sh
cd android
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

预览包输出：`android/app/build/outputs/apk/debug/app-debug.apk`。预览包 application ID 为 `app.codexweb.mobile.debug`，正式包为 `app.codexweb.mobile`。预览签名不是正式发布密钥；不同机器生成的 debug key 可能不能覆盖安装，卸载会清除 App 本地状态。

正式发布需要维护者在 Android Studio 中自行配置签名并生成 Signed Bundle/APK；仓库不提供签名私钥，也不自动把 release 构建签成 debug 包。

仓库根目录：

```sh
npm ci
npm run lint
npm test
npx playwright install chromium
npm run test:mobile
```

浏览器测试使用模拟 API，覆盖小屏布局、入口可达、输入法换行、工具关闭、Review、草稿不被面板切换清空、窄视口输入可见性与桌面布局回归。不会访问生产账户或执行真实任务。设置 `MOBILE_SCREENSHOT_DIR` 可保存 390 px 布局截图。这些测试**不等于真机软键盘或完整端到端业务验收**。

Android 单元测试覆盖地址规范化、origin/端口隔离、危险 scheme、路径穿越和编码路径拒绝。CI 另行构建 APK 并运行 lint / 单元测试；下载构建产物只用于测试，不代表已上架。

## 发布前验收（需要时阅读）

- 至少两台实体安卓设备，覆盖 Android 8.x 与较新系统；中文输入法、手势返回、系统字体放大、横竖屏和深色模式。
- 使用测试账号验证登录、退出、切换主机、证书错误、VPN 断线重连；确认无跨账号或跨服务草稿混入。
- 上传图片/PDF/多文件、取消选择、授权拒绝；下载中文文件名、大文件、登录失效、跨域重定向和进程被回收。
- 真实任务的排队、引导、停止、后台运行、结果恢复；编辑重发和 Fork 保持原语义。
- 麦克风拒绝与再次授权、系统设置撤销权限、录音中切后台、服务端转写错误；确认不意外发送。
- 所有矩阵入口逐项走通，长代码/表格/公式不挤出界面，TalkBack 朗读顺序与焦点恢复符合预期。
- 在实机记录启动耗时、长对话滚动和键盘弹出体验，再决定是否将特定页面迁移到原生 UI。

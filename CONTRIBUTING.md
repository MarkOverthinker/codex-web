# Contributing

Issues and pull requests are welcome. Keep changes focused, add or update tests for behavior changes, and run `npm test` before opening a pull request.

Never include credentials, personal server paths, production logs, database snapshots, Codex authentication data, or user files. By contributing, you agree that your contribution is licensed under the MIT License.

Enable the staged-content, commit-message and outgoing-history checks with `git config --local core.hooksPath .githooks`. Normal Git author names and emails are accepted; do not put private machine or deployment details in source or commit messages. Run `npm run check:privacy` before publishing. See [public repository privacy](docs/PUBLIC_PRIVACY.md) when needed.
